How It Works

Notes in, structured data out

Write in plain language. AI extracts structured data automatically. Query everything with SQL.

01

Write

Daily notes in a markdown editor. Logs, meals, workouts, whatever you track.

Ran 5k in 24:32 this morning.
Had coffee with Sam, talked about
the new project deadline on Friday.
→
02

Extract

AI parses your notes and extracts structured entities, metrics, and relationships.

exercise: running, 5k, 24:32
person: Sam
event: project deadline, Friday
→
03

Query

Ask questions in natural language. Get SQL-powered answers from your own data.

> "Average 5k time this month?"

SELECT avg(duration)
FROM exercises
WHERE type = 'running'

Features

Everything you need, nothing you don't

Built for developers who want their data close and their tools sharp.

01

Local-first storage

DuckDB on your machine. Your data never leaves unless you want it to. Zero cloud dependency.

02

Markdown editor

Milkdown-powered WYSIWYG with full markdown support. Write notes the way you think.

03

SQL query engine

Ask questions in plain English. Get DuckDB-powered SQL queries against your extracted data.

04

Smart extraction

AI identifies exercises, people, events, metrics, and more from unstructured text automatically.

05

Self-hostable

One docker compose up and you are running. No accounts, no signup, no telemetry. Ever.

06

Cloud option

Optionally deploy with Neon Postgres and Clerk auth for multi-device sync and sharing.

07

Daily notes

Date-indexed journal entries. Navigate by calendar. Build a searchable record of your life.

08

Open source

MIT licensed. Fork it, extend it, self-host it. Full access to the codebase, no strings attached.

⚡

Works without AI

No API key? No problem. Unstructured Minds is a fully functional notes app even without AI. Write daily notes, organize by date, search your entries. Add an API key later when you want extraction and querying superpowers.

Get Started

Up and running in 60 seconds

Two paths. Same app. Pick the one that fits.

Local mode

Recommended
# Clone and start
$ git clone https://github.com/unstructured-minds/unstructured-minds
$ cd unstructured-minds
 
# Add your API key (optional)
$ echo "ANTHROPIC_API_KEY=sk-..." > .env
 
# Launch
$ docker compose up

Cloud mode

Multi-device
# Configure environment
$ cp .env.example .env
 
# Set required variables
USE_CLOUD=true
DATABASE_URL=postgres://...
CLERK_SECRET_KEY=sk_live_...
 
# Launch
$ docker compose up
