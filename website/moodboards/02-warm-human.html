Features

Everything you need, nothing you don't

A thoughtful set of tools for people who think by writing.

📝

Rich Markdown Editor

Beautiful WYSIWYG editing powered by Milkdown. Write in markdown without seeing the syntax.

🗃️

Self-Hostable

One Docker Compose command. Runs on your laptop, a Raspberry Pi, or your own server.

🤖

Smart Extraction

AI reads your free-form notes and creates structured data -- exercises, meals, habits, anything.

💬

Natural Language Queries

Ask questions about your data in plain English. No SQL knowledge needed.

🌐

Local or Cloud

DuckDB for local speed, Postgres for cloud scale. Switch modes with one env var.

🔒

Privacy First

Your notes, your database, your API keys. No telemetry, no tracking, no accounts required.

📅

Daily Notes

Built-in daily note workflow. Open today's page and start writing -- it's always there.

🚀

Fast & Lightweight

React 19 frontend, FastAPI backend. Snappy even on modest hardware.

Get Started

Running in under a minute

Three steps. No accounts to create, no forms to fill out.

1

Clone the repo

Grab the source code from GitHub. Everything you need is included.

git clone https://github.com/...
2

Start it up

One command spins up the frontend, backend, and database.

docker compose up
3

Start writing

Open your browser and write your first note. Add an API key later if you want AI features.

open http://localhost:3000
