How It Works

Write freely. Let AI do the filing.

You take notes the way you think -- messy, fast, human. Unstructured Minds reads your natural language and extracts structured data in real time. No tagging. No forms. Just write.

What you write

4x10 rows at 135. Energy was
high, slept well last night.

Also been reading "Designing
Data-Intensive Applications"

Every note you take becomes a row in a database you can query, chart, and learn from.

Intelligence Layer

Bring your own AI

Unstructured Minds uses Claude as its intelligence layer -- fast extraction with Haiku, sophisticated queries with Sonnet. Your API key, your control, your data.

No data leaves your infrastructure unless you choose it to. Self-host everything, or use the managed cloud mode.

  • Claude Haiku 4.5 Data extraction
  • Claude Sonnet 4.5 Natural language queries
  • Your API key Full ownership
  • Local or Cloud Your choice of mode

Capabilities

Built for people who think in prose

Every feature is designed around one idea: your notes are valuable data, not just text files.

01

Milkdown Editor

A beautiful WYSIWYG markdown editor that stays out of your way. Write in markdown, see it rendered. No mode switching.

02

Real-Time Extraction

As you write, AI identifies exercises, moods, readings, habits, and any structured data -- automatically classified and stored.

03

Natural Language Queries

Ask questions like "What was my average bench press last month?" and get instant answers from your structured data.

04

Daily Notes

One note per day. A simple constraint that turns your notes into a personal journal with structured data over time.

05

Self-Hostable

Run it on your own hardware with Docker Compose. Your data stays on your machine, your network, your terms.

06

Analytics Dashboard

Visualize trends across your extracted data. See patterns in your habits, track progress, discover insights you never knew were in your notes.

Architecture

Two engines,
one interface

Choose your storage layer based on your needs. Both modes share the same API, the same UI, and the same AI pipeline.

DB

DuckDB

Local mode

An embedded analytical database that runs as a single file on your machine. Zero configuration, zero network calls.

  • Single-file storage
  • No server process
  • Columnar analytics
  • Instant local queries
or
PG

Postgres

Cloud mode

Neon serverless Postgres for multi-device access with DuckDB as an in-memory analytics cache.

  • Serverless scaling
  • Multi-device sync
  • Clerk authentication
  • DuckDB analytics cache

Getting Started

Up and running
in three steps

No complicated setup. No managed services required. Just Docker and an API key.

Clone the repository

Grab the source and navigate into the project directory.
git clone https://github.com/unstructured-minds/app.git

Add your API key

Create a .env file with your Anthropic API key. That is the only required configuration for local mode.

Start writing

Run docker compose up and open your browser. Your notes are now a database.
