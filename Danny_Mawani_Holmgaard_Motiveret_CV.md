## Motivation

Jeg søger stillingen som AI-platformsudvikler hos Akademikernes A-kasse, fordi den rammer præcis i krydsfeltet mellem det, jeg brænder for, og det, jeg har bygget min karriere på: at skabe skalerbare, AI-drevne platforme, der gør en reel forskel for de mennesker, der bruger dem.

Som grundlægger af Unstructured Minds har jeg selv designet og bygget en fuld AI-platform fra bunden — med FastAPI-backend, React TypeScript-frontend, Docker-containerisering og Claude som intelligence layer. Platformen transformerer ustruktureret data til strukturerede, forespørgbare indsigter via LLM-drevne workflows. Parallelt har jeg i mine roller som Principal Cloud Developer og Data Architect opbygget solid erfaring med at designe og drifte komplekse dataplatforme i Azure med CI/CD, Infrastructure as Code og tæt forretningssamarbejde.

Jeres vision om en DAG-baseret AI-platform, der gør det muligt for medarbejdere at bygge AI-augmenterede workflows, lyder som noget, jeg både forstår dybt og brænder for at være med til at videreudvikle. Jeg er klar til at tage teknisk ejerskab og bidrage med både hands-on udvikling og arkitektonisk overblik.

## Eget Projekt: Unstructured Minds

[github.com/dannymawani/unstructured-minds](https://github.com/dannymawani/unstructured-minds)

Full-stack AI-platform, der transformerer ustrukturerede noter til strukturerede, forespørgbare data via LLM-drevet ekstraktion. Bygget som containeriseret webapplikation med fokus på skalerbarhed og brugeroplevelse.

| | |
|---|---|
| **Tech stack** | Python (FastAPI), React 19 + TypeScript, Tailwind 4, DuckDB/Postgres |
| **AI/LLM** | Claude API (Haiku 4.5 + Sonnet 4.5), AI-drevet dataekstraktion og NL-queries |
| **Infrastruktur** | Docker Compose, CI/CD, multi-environment deployment |
| **Features** | DAG-baserede workflows, dashboards, kanban, kalender, NL-søgning, kommandopalet |
