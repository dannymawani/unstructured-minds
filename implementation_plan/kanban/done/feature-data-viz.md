## Description

Create rich, interactive data visualizations for extracted metrics and trends.

## Tasks

- [ ] Workout volume over time

## Acceptance Criteria

- Interactive charts with tooltips
- Date range selection
- Multiple data series overlay
- Export charts for sharing
- Mobile-friendly charts

## Visualization Types

1. **Line Chart**: Trends over time (weight, sleep)
2. **Bar Chart**: Comparisons (exercises, weekly counts)
3. **Heatmap**: Calendar view (activity, mood)
4. **Scatter Plot**: Correlations (sleep vs mood)
5. **Pie/Donut**: Distributions (task categories)
